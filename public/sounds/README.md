# Sons de alerta do Painel SGA

Os arquivos de áudio desta pasta são servidos pelo Vite em `/sounds/` (ou no caminho-base configurado para a aplicação). Os sons configurados atualmente são:

- `ekiga-vm.wav`
- `doorbell-bingbong.wav`
- `toydoorbell.wav`
- `airport-bingbong.wav`
- `ding-dong.wav`
- `infobleep.wav`
- `quito-mariscal-sucre.wav`

Para adicionar um som, copie um arquivo `.wav`, `.mp3` ou `.ogg` para esta pasta e adicione uma opção no `<select id="alert-sound">` do arquivo `src/App.vue`. Use o nome do arquivo, incluindo a extensão, como valor da opção.
